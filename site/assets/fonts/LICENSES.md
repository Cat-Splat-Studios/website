# Font licences

All three faces are self-hosted rather than loaded from a CDN, so the site makes no
third-party requests. Each is licensed under the SIL Open Font License 1.1, which permits
redistribution and web embedding.

| File | Family | Author | Licence |
|---|---|---|---|
| `PixelifySans-SemiBold.ttf` | Pixelify Sans | Stefie Justprince | SIL OFL 1.1 |
| `SpaceMono-Regular.ttf` | Space Mono | Colophon Foundry | SIL OFL 1.1 |
| `PixelOperatorMono-Bold.ttf` | Pixel Operator Mono | Jayvee Enaguas (HarvettFox96) | SIL OFL 1.1 |

The full licence text is bundled here as [OFL.txt](OFL.txt), because clause 2 requires it to
travel with the fonts, so it ships with the site rather than being linked.

These are the same files shipped in *Sentinels of Gleamwood*
(`Assets/_Game/UI/Fonts/`), which is why the site's type matches the game's UI exactly.
If the game's fonts change, copy the new files here to keep them in sync.
